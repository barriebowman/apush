# APUSH

Instructional materials for AP U.S. History: interactive lessons, review exhibitions, and classwork built around the course's key concepts.

## Building Slavery: A Colonial Exhibition

An interactive, walk-through exhibition on the origins of British colonial slavery (1619 to 1740), built for Key Concept 2.6. Six rooms of primary source objects, a legal document archive, and a companion classwork booklet.

**[View the exhibition](https://barriebowman.github.io/apush/building-slavery-exhibition.html)**
